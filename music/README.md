# TAPPY Music

This folder is for audio tracks that you own or are licensed to use with TAPPY.

## Supported playback

TAPPY's music MCP tool expects a direct HTTP/HTTPS URL to an **Ogg audio** file/stream.

Example:

`https://raw.githubusercontent.com/tharuldasan/xiaozhi-esp32/main/music/example.ogg`

## MCP controls

- `self.music.play_url` — play a direct Ogg URL
- `self.music.stop` — stop the current music

Do not add copyrighted recordings unless you have the right to host and play them.
